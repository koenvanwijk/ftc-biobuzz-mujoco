Un-mirror (2026-10)
-------------------
Until 2026-10 the import used (x,y,z)->(x,z,y). det = −1, so that was a reflection:
the whole sim field was manual Fig. 9-2 / Guide Fig. 6-2 mirrored in Y (audience at +Y with red
still at −X, so red was on the RIGHT seen from the audience; tile rows had been flipped to match).
Now: CAD_TO_SIM = (x,y,z)->(x,-z,y) (scripts/convert_field_cad.py), a proper rotation.
Audience wall = −Y, red alliance wall = −X (red on the left seen from the audience),
columns A→F = −X→+X, rows 1→6 = −Y→+Y. new = diag(1,−1,1) · old for all CAD-derived content.

Migration (scripts/convert_field_cad.py migrate --legacy), all three mesh copies
(ftc_sim/assets/meshes, web/public/assets/meshes, web-blocks/public/assets/meshes):
  world-frame meshes (hive_*, flower_*) × diag(1,−1,1); cell-local meshes (cell_*) ×
  diag(−1,1,1); faces re-wound because det < 0 (trimesh), so normals stay outward
  (hull signed volumes unchanged and > 0, e.g. hive_frame_hull +0.7524 m³).
  flower_pos_y.stl ↔ flower_neg_y.stl swapped names (they swap sides of the field).
