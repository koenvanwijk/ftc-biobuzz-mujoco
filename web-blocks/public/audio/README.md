# Robot recordings

The four original user-provided M4A recordings, preserved byte-for-byte (no
synthesized substitutes or re-encoding). All contain mono AAC at 44.1 kHz.

| File | Trigger | Duration |
| --- | --- | --- |
| `flywheel.m4a` | Flywheel motor active (power or velocity) | 7.430 s |
| `intake.m4a` | Intake active, including reverse | 3.529 s |
| `drive.m4a` | Either resolved drive motor active | 5.039 s |
| `collision.m4a` | New robot impact, once (not a loop) | 2.113 s |

Motor recordings loop as supplied, at their original speed. Enable playback with
**Geluid aanzetten** in the simulator; the click supplies browser autoplay permission.
